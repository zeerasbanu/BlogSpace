# BlogSpace

A beginner-friendly frontend blogging project built with HTML, CSS and JavaScript.

## Run the project
1. Extract the ZIP file.
2. Open the `BlogSpace` folder in Visual Studio Code.
3. Install the **Live Server** extension if you do not already have it.
4. Right-click `index.html` and choose **Open with Live Server**.

## Try the application
1. Open Register and create an account.
2. You will be taken to your dashboard.
3. Choose **Write a story**, fill in the form and publish or save a draft.
4. Edit or delete your posts from the dashboard.
5. Log out and log back in to test the demo login.

## Project structure
- `index.html` — public home page
- `login.html` — login form
- `register.html` — registration form
- `dashboard.html` — your posts and statistics
- `create-blog.html` — create and edit posts
- `css/` — page styles
- `js/` — application logic
- `assets/images/` — folder for your own image files

## Important note
This is a frontend learning demo. It stores demo accounts and posts in the browser's LocalStorage. Passwords are not securely protected, and data is only available in the same browser. Do not use real passwords or sensitive information. A production application needs a secure backend and database.

Some sample cover photos and Google Fonts load from the internet.
